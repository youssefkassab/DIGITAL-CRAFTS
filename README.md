## 📋 Project Overview

**Mission:** "Wipe the illiteracy of digital skills in Egypt"

DIGITAL CRAFTS is a static marketing website for an online course platform offering programming and digital skills education. Built with modern web standards, featuring smooth animations, responsive design, and professional UI components.

---

## 🎨 Features

| Feature | Implementation |
|---------|----------------|
| **Responsive Design** | Bootstrap 5.3 grid system |
| **Animations** | Animate.css + Wow.js |
| **Image Carousel** | Owl Carousel 2 |
| **Icons** | Font Awesome 5 + Bootstrap Icons |
| **Course Pages** | Dedicated Python course landing |
| **Multi-page** | 10+ HTML pages (Home, About, Courses, Team, Testimonials, Contact, Pricing) |
